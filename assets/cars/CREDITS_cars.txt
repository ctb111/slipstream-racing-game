Car models (assets/cars/*.glb). Licences checked against the Sketchfab API
(api.sketchfab.com/v3/models/<uid>) and the glTF asset.extras / license.txt
shipped with each copy. None were downloaded from Sketchfab directly (no
account): each came from a public GitHub repo that mirrors the Sketchfab export.
All were decompressed / converted for Godot with glTF-Transform (Draco and
quantization removed; WebP textures converted to PNG; some meshes simplified).
