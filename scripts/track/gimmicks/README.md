# scripts/track/gimmicks/

The **Gx kit**: set pieces that make each circuit memorable (bridges and overpasses you drive under,
warehouses and barns you drive through, fan banks with flares, graffiti, billboards, painted road messages,
ski lifts, helicopters, wind turbines ...) plus the per-track dressing that places them, and the landscape
filler that fills the middle distance of every track.

It runs as one `Circuit.EXTRA_BUILDERS` entry, `gimmicks.gd`, after the themes and before the forest:

```
gimmicks.gd  build(c, ...)
  GxTest.maybe_run(c)                    debug only (--gx_test)
  dress_<def.id>.gd  dress(c)            per-track placement of Gx pieces (if the file exists)
  fill_landscape.gd  fill(c)             fields, farms, hedges, tree lines, telegraph lines 20-300 m out
  gx_fans.gd         flush(c)            builds every crowd piece placed above in one merged batch
```

## The contract (from `gx.gd`)

- **Piece**: `gx_<piece>.gd` with `class_name Gx<Piece>` and
  `static func place(c: Node3D, xf: Transform3D, opts := {}) -> void`. Usage examples are in each file's
  header.
- **Dressing**: `dress_<track_id>.gd` (no class_name) with `static func dress(c: Node3D) -> void`; called
  automatically for the matching track id. Template: `dress_example.gd.txt`.
- **Frames**: `Gx.frame(c, along, side, lateral)` is a transform `lateral` m beyond the road edge on `side`
  (`Gx.LEFT` / `Gx.RIGHT`), `along` m round the lap from the start line, standing on the terrain, **+z away
  from the road**, so a piece built facing -z faces the road. `Gx.road_frame(c, along)` is centred on the
  road, x along the track, for things that span it. The basis is never mirrored (on the left side +x runs
  against the driving direction; use `Gx.frame_x()` for the driving direction).
- **Footprints**: `Gx.reserve(c, pos, radius)` keeps trees and later pieces away; `GxSpot.find(...)` finds a
  free, flat spot clear of the road and of all reservations.
- **Determinism**: `Gx.rng(c, purpose)` is seeded from the track id and purpose, so every machine builds the
  same dressing.

## Files

### Core and helpers

| File | class_name | What it is |
|---|---|---|
| `gimmicks.gd` | (none) | The `EXTRA_BUILDERS` entry described above. |
| `gx.gd` | `Gx` | Placement helpers: `curve`, `length`, `centre`, `tangent`, `ground`, `frame`, `frame_x`, `road_frame`, `clear_of_road`, `reserve`, `corners` (sharpest first, `{along, turn, strength}`), `straights` (`{from, to}`), `rng`, `add_mesh` (one merged mesh with a padded, fading visibility range). |
| `gx_geo.gd` | `GxGeo` | Merged-mesh builder for pieces: bevelled boxes, profile extrusions, tube sweeps, lathes, printed sign quads, merged per material into one `MeshInstance3D` each plus one `StaticBody3D` of box colliders. `var g := GxGeo.new(xf); g.box(...); g.commit(c, ...)`. |
| `gx_spot.gd` | `GxSpot` | Finds a free flat footprint beside the road (`GxSpot.find`, `GxSpot.near_start`). |
| `gx_props.gd` | `GxProps` | Poly Haven CC0 models from `assets/industrial/` as MultiMeshes (`scatter`) and procedural props (pallets, forklift, tractor, containers, hay bales) added into a `GxGeo`. |
| `gx_spin.gd` | `GxSpin` | Node that turns about its local z (rotors); stops when not visible. |
| `gx_road_glyphs.gd` | `GxRoadGlyphs` | GENERATED by `tools/make_gx_road_text.py`: glyph order and advance widths. Do not edit. |

## How it connects

- Called from `scripts/track/circuit.gd` through `EXTRA_BUILDERS` (`gimmicks.gd`).
- Reads the circuit through `c.get("curve")`, `c.get("start_offset")`, `c.get("terrain")`, `c.get("def")`
  and the `no_trees` meta.
- Builds with `TracksideKit` and `PeopleKit` (`scripts/track/trackside_kit.gd`, `scripts/world/people.gd`),
  `Mats` (`scripts/world/materials.gd`), `FacadeKit`, `CarModel` (parked cars).
- Uses atlases and models in `assets/gimmicks/`, `assets/industrial/`, `assets/camp/`, `assets/trackside/`.

## Gotchas

- **Clearance**: anything over the road needs at least **5.5 m** clear height and must keep out of the road
  footprint plus 1.5 m. Solid parts off the road get collision (`StaticBody3D`, low friction; `GxGeo`
  colliders do this).
- **Guard optional pieces**: dressing files check `ResourceLoader.exists()` (or helpers like `_piece()`)
  before calling a piece, so removing a piece file never breaks a track.
- **Visibility ranges are measured to the AABB centre**: `Gx.add_mesh` already pads `vis_end` by the AABB
  half-diagonal and fades with `FADE_SELF` over a 10 % margin. If you set ranges by hand, do the same.
  Remember `FADE_SELF` goes through the transparent pipeline while fading; use `visibility_parent` for LOD
  swaps.
- **Never fix fps by shortening view ranges**; nothing may appear out of nowhere ahead. Check with
  `--pop-audit`.
- **Real photo textures** for signs, graffiti and posters, and invented brand names only (no logos, no real
  sponsors).
- **Typing**: option dictionaries are untyped, so `var w := opts.get("width", 40.0)` fails to infer; write
  `var w: float = opts.get("width", 40.0)`.
- Altstadt has the least frame-time margin; keep its dressing light.

## Where to start reading

`gx.gd` (header and helpers), `dress_example.gd.txt`, then one full dressing such as
`dress_valle_club.gd`, and one piece such as `gx_overpass.gd` with `gx_geo.gd` beside it.
